# TiPillTabs iOS sources

See ../README.md for the public API, installation and sticky-header examples.

- Classes/TiPilltabsModule.swift: module identity.
- Classes/TiPilltabsViewProxy.swift: Titanium view bridge and UIKit control.
- TiPillTabs.xcodeproj: generated Titanium Swift module project.
- dist/ti.pilltabs-iphone-1.1.0.zip: build output.

Minimum iOS version: 17.0. SDK used: 13.4.1.GA. MIT license.
